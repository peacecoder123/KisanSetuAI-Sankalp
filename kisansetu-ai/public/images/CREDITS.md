# Images & Credits

All graphics and charts used in this prototype are generated via code (SVG/Recharts) or use placeholder/public domain icons from Lucide. 

No proprietary real-world satellite imagery or sensitive PII is included in the codebase. All names (e.g., Ramesh Patil) and coordinate plots are illustrative mock data for the SankalpPS hackathon.

- **Icons**: Lucide React
- **Brand Logo & Favicon**: Custom inline SVGs generated specifically for KisanSetu AI
- **Map & Heatmap visualisations**: Rendered via pure CSS/SVG and Recharts
